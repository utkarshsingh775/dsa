How to run this round

  • Time-box each problem. Core: 20 min, Pro: 35 min. If you hit the limit, read the approach, close it, and code it again yourself the next day. Mark it ★.
  • Say the approach out loud before coding: brute → better → optimal, with the complexity of each. You have solved these before, so recall is what you are training now.
  • DP: write the recurrence first, then memo → tabulation → space-optimised. Do all three only for the first problem of each pattern. After that, go straight to tabulation.
  • Weekends clear the backlog, then go back over the ★ list. Use the module contests as checkpoints.
  • Skip Fundamentals of Programming / Language Basics / Patterns if you want. They are in the final day only so that 100% means 100%.
